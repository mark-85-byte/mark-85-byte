## Projects

### [Browser Report Diff](https://github.com/mark-85-byte/browser-report-diff)

An MIT-licensed Python tool for comparing browser diagnostic JSON reports offline. It highlights changed measurement paths, ignores sampling timestamps, distinguishes missing values from null, and supports numeric tolerance.

- Uses only the Python standard library.
- Includes runnable fictional examples and regression tests.
- Status: initial public release, developed with AI assistance.

### [Browser compatibility diagnostics](https://github.com/mark-85-byte/browser-compatibility-tests)

A Python diagnostics project for comparing browser behavior across Windows, macOS and Linux. The current implementation records the execution environment, browser version, graphics renderer, canvas sample repeatability, font measurements and screen dimensions.

- Focus: explicit environment information and understandable diagnostic reports.
- Status: early-stage public development under the MIT license.
- Includes offline report comparison, contribution guidance and regression tests.

## Community notes

### Claude for Open Source: try Edge if Submit is unresponsive

If the Claude for Open Source form shows GitHub verification as complete but clicking **Submit** produces no visible response, try opening the [official application form](https://claude.com/contact-sales/claude-for-oss) in **Microsoft Edge**.

In my test, Edge displayed the application submission confirmation.

1. Open the official form in Edge.
2. Sign in with GitHub and select your repository.
3. Complete the required fields and submit.
4. Allow time for the confirmation message to appear before retrying.

This troubleshooting tip is based on one successful submission; browser behavior may vary.
